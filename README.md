# AI-for-Neuromorphic-Emotional-Behaviour-Modeling
Neuromorphic emotion recognition from EEG using the DEAP dataset. Preprocesses signals (4-45 Hz bandpass, 4 s windows), extracts band-power features, and classifies valence and arousal with a spiking neural network (snnTorch, LIF neurons, rate coding), benchmarked against an SVM baseline. Built in Python with a Jupyter notebook.
